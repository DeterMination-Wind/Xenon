## 中文

Xenon v1.10.0 是一个稳定性修复版本，修复了点击“开始游戏”时因找不到可用的 Java 运行时而直接崩溃的问题。

### 主要更新

- 修复启动游戏时 Java 运行时解析为空导致 `NullPointerException` 崩溃的问题（例如在部分新安装环境或 Java 安装位置异常时）。
- 启动器现在会优先回退到自身携带的 Java 环境，仅在完全无法解析时给出明确的错误提示，不再静默崩溃。
- 加固了游戏启动前的 Java 环境检测与异常处理链路。

### 校验

- 通过 XenonCore 全量测试、Checkstyle 和 Xenon 编译验证。

## English

Xenon v1.10.0 is a stability release that fixes a crash when clicking **Play** while no usable Java runtime could be resolved.

### Highlights

- Fixed a `NullPointerException` crash during game launch when the Java runtime resolved to null (e.g. on fresh installations or when Java is installed in an unusual location).
- The launcher now prefers falling back to its own bundled Java environment, and only shows a clear error message when no Java can be resolved at all — no more silent crashes.
- Hardened the Java environment detection and error-handling pipeline before launching the game.

### Verification

- Passed the full XenonCore test suite, Checkstyle, and Xenon compilation.
