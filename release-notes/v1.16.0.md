## 中文

### 本次新增

- **下载限速**：整条 Mindustry 下载链路共用一个额度，可选不限速 / 1 / 2 / 5 MB/s，也可以自己填 KB/s（最低 32 KB/s）。改动立即生效，正在下载的任务也会跟着变
- **下载来源可选四档**：优先国内源 / 优先官方源 / 仅国内源 / 仅官方源。切换后版本列表和变体入口会一起联动，没有可用来源的变体会置灰并写明原因
- **下载完成后校验来源清单**：比对文件大小与 SHA-256，一旦不符就删掉重下、同源再试一次，仍失败就换到另一侧来源
- **启动后自动检查云存档（只读）**：比对本地与云端，发现冲突时给出提示，可以自己选择用云端覆盖本地（先备份）、保留本地并上传，或者稍后处理
- **云端空间不足时自动清理**：上传前先腾出空间，只删最旧的未固定快照，固定项和最新一份永远不会被删，每次删除都会先记入日志

### 本次改动

- **竞品对比表全量复核**：逐个仓库核对平台、形态、最后更新与各项能力，新增「Java 管理」与「下载来源策略」两行，并补充三个同样支持 Windows 的启动器

## English

### Added

- **Download rate limiting**: one shared budget for the whole Mindustry download chain, with unlimited / 1 / 2 / 5 MB/s presets or a custom KB/s rate (32 KB/s floor). Changes apply immediately, including to downloads already running
- **Four download source tiers**: prefer domestic / prefer official / domestic only / official only. The version list and the variant entries follow the tier, and a variant with no allowed source is disabled with the reason shown
- **Downloads are verified against the source manifest**: file size and SHA-256 are checked, a mismatch deletes the artifact and retries the same source once, and a second failure switches to the other source
- **A read-only cloud-save check after startup**: local saves are compared with the cloud, and conflicts are reported so you can overwrite local from the cloud (backed up first), keep local and upload it, or decide later
- **Automatic cleanup when the cloud is full**: uploads make room first by dropping only the oldest unpinned snapshots. Pinned snapshots and the newest one are never deleted, and every deletion is logged before it happens

### Changed

- **The competitor table was re-verified end to end**: every repository was checked for platform, form, last update and each capability, adding new Java management and download source policy rows plus three more Windows-capable launchers
