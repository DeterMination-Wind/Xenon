## 中文

Xenon v1.11.0 改进了原版 Mindustry 的下载体验，针对中国大陆用户接入 MDTbbs 镜像，并增加了更高效的归档下载能力。

### 主要更新

- 中国大陆用户下载原版 Mindustry 时，默认使用 [MDTbbs Mindustry v8 镜像](https://file.mdtbbs.cn/category/Mindustry/v8)。镜像不可用时会自动回退到 GitHub 官方源。
- 支持从镜像识别并下载 Windows、Linux 和 macOS 版本，并从归档中提取启动器需要的 `Mindustry.jar`。
- 对支持 HTTP Range 的镜像归档启用分段并行下载，最多使用 16 个分段并受启动器下载并发设置限制；不支持 Range 时自动退回单线程下载。
- MDTbbs 文件下载链接会附加 `?reques=Xenon+1.11.0`，用于标识下载来源；目录请求和 GitHub 回退请求不会附加该参数。
- 其他地区及 Mindustry BE、MindustryX、CNArc 等版本源保持原有行为。

### 校验

- 通过 XenonCore 全量测试、Xenon 编译和完整 Gradle 构建验证。

## English

Xenon v1.11.0 improves vanilla Mindustry downloads by adding a mainland-China mirror and more efficient archive transfers.

### Highlights

- Mainland China users now receive original Mindustry builds from the [MDTbbs Mindustry v8 mirror](https://file.mdtbbs.cn/category/Mindustry/v8) by default, with an automatic GitHub fallback when the mirror is unavailable.
- The mirror integration recognizes Windows, Linux, and macOS builds and extracts the `Mindustry.jar` required by the launcher.
- Archives served with HTTP Range support are downloaded in bounded parallel segments, up to 16 segments and limited by the launcher's download concurrency setting. Unsupported Range responses automatically fall back to a single stream.
- MDTbbs file URLs include `?reques=Xenon+1.11.0` for download attribution. Directory and GitHub fallback requests are left unchanged.
- Existing sources for other regions and Mindustry BE, MindustryX, and CNArc remain unchanged.

### Verification

- Passed the full XenonCore test suite, Xenon compilation, and the complete Gradle build.
