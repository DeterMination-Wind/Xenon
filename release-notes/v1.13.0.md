## 中文

Xenon v1.13.0 把 MDTBBS 社区搬进了启动器，并加入资源中心、云存档和联机辅助。

### 主要更新

- 左侧新增「社区」：原生浏览 MDTBBS 版块与帖子、搜索、阅读正文与回复、发帖、回复、点赞收藏和通知，全程无需打开网页。
- 支持 MindAuth 登录：在系统浏览器完成授权后回到启动器；帖子与回复的作者名可点击打开主页。
- 下载页新增「资源」：浏览与搜索 MDTBBS 蓝图和地图，预览后一键安装到所选实例；也可以从启动器上传蓝图或地图，进入论坛审核流程。
- 每个实例新增「云存档」：云端槽位与历史快照、上传、恢复（恢复前自动备份本地文件）、固定版本和额度显示。
- 好友与联机：显示在线状态和「正在玩」动态，提供好友与联机邀请面板，并支持 `xenon://join?intent=` 一键调起启动器。当前完成联机信令，进入游戏仍需在 Mindustry 内加入服务器。

### 修复与优化

- 打包时校验 OkHttp 依赖的 Kotlin/Okio 类，避免裁剪配置误删导致运行时报错。
- 修复关闭 JFoenix 弹窗可能触发的 JavaFX 空指针。
- 版本被删除或实例配置损坏时不再崩溃：列表显示「该版本已不存在」，启动前给出明确提示。
- GitHub 接口返回异常格式时显示可读错误，不再抛出解析异常。
- 资源预览最多同时下载三张，避免给论坛造成压力。

### 验证

- 通过 Xenon / XenonCore 编译、Checkstyle 与新增单元测试（社区客户端、OAuth、CSRF、清单解析等）。

## English

Xenon v1.13.0 brings the MDTBBS community into the launcher, together with a resource center, cloud saves and multiplayer helpers.

### Highlights

- New "Community" page in the sidebar: browse MDTBBS categories and threads, search, read formatted posts and replies, create threads, reply, like, bookmark and view notifications without a browser.
- MindAuth sign-in: authorize in the system browser and return to the launcher automatically; author names open their forum profile.
- New "Resources" tab in the download page: browse and search MDTBBS blueprints and maps, preview them and install with one click into the selected instance, or upload new content for forum moderation.
- Cloud saves for every instance: cloud slots and history, upload, restore with an automatic local backup, pinning and quota display.
- Friends and multiplayer helpers: presence and "playing now" activity, a friends and invites dialog, and `xenon://join?intent=` deep link handling. Signalling is implemented; entering the game still happens inside Mindustry.

### Fixes and improvements

- The shadow jar build verifies the Kotlin/Okio classes required by OkHttp, so dependency minimization cannot silently drop them.
- Fixed a JavaFX null pointer that could happen when a JFoenix popup was hidden twice.
- Deleted versions or corrupted instances no longer crash the launcher; the list shows "This version no longer exists" and launching shows a clear message.
- Unexpected GitHub API responses now produce a readable error instead of a Gson parse crash.
- Resource previews are limited to three concurrent downloads to avoid stressing the forum.

### Verification

- Passed Xenon / XenonCore compilation, Checkstyle and the new unit tests (community clients, OAuth, CSRF, manifest parsing and more).
