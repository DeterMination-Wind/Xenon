## 中文

### 本次新增

- **云存档上传显示进度**：上传过程中对话框会显示百分比进度条，托盘菜单同步显示同一条状态，上传结束后自动消失
- **Java 运行环境缺失时的引导**：实例配置的 Java 不存在时不再只抛出 `CreateProcess error=2`，而是弹出对话框写明缺失的路径，并可一键进入「设置 → Java 管理」并自动打开运行时下载框

### 本次改动

- **能启动优先**：挑选 Java 时会跳过 Java 池里已经失效的条目，自动回退到可用的运行时，不再因为一条失效记录而启动失败
- **上传失败会交还会话**：上传或提交失败时，启动器会把服务端的上传会话交还给服务器，避免残留占位；交还失败也不会影响原始报错
- **竞品对比表复核到 2026-10-18**：补充 Copper 的云存档与 Windows 拖出文件、GXFQE 的命令行，并新增「移动端 / 其他平台启动器」一览

## English

### Added

- **Cloud-save uploads show progress**: the dialog displays a percentage bar while an upload runs, the tray menu mirrors the same status line, and both disappear once the upload settles
- **Guidance when the Java runtime is missing**: an instance whose configured Java is gone no longer only reports `CreateProcess error=2`; a dialog names the missing path and offers one click to Settings → Java management with the runtime download dialog already open

### Changed

- **Launching wins over failing**: the Java picker skips stale entries in the Java pool and falls back to a working runtime, so one stale record can no longer block a launch
- **Failed uploads hand their session back**: when the PUT or the commit fails, the launcher returns the server-side upload session instead of leaving it behind, and a failed cleanup never hides the original error
- **The competitor table was re-verified as of 2026-10-18**: Copper's cloud saves and Windows file drag-out, the GXFQE command line, and a new mobile / other-platform launcher list
