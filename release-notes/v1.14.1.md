## 中文

Xenon v1.14.1 是一个修复版本：修正社区 mod 安装的文件名与重复安装问题、无法识别的发布包，以及 MDTBBS 云存档、通知、好友状态、地图详情与在线活动在当前 `/api/v1` 契约下的解析问题。

### Mod 管理

- 从社区索引与 GitHub 直装 mod 时，安装文件沿用 Release 资源名（例如 `LogicSugar-v5.7.0.jar`），不再使用临时下载名。
- 安装同一 mod 的新版本会替换旧文件（按 mod 内部名称匹配），不再出现两个同名内部 mod 并排、游戏只加载其中一个的情况；若目标文件名属于另一个 mod，则自动改用带编号的新名字，绝不覆盖。
- 只有扩展名像 mod、但压缩包内没有 `mod.hjson`/`mod.json` 的发布包（例如 `Mod.zip` 包着 `Mod.jar`、源码包）会被识别为「无法识别」列在列表末尾并给出原因；从这些文件安装会直接报错，而不是把无效文件放进 `mods/`。
- 已装列表在存在无法识别文件时显示「已安装 N 个 mod，另有 M 个文件无法识别」。

### MDTBBS 社区功能（对齐当前 `/api/v1` 契约）

- 云存档：修复上传与下载地址被拼成 `/api/v1/api/v1/...` 的问题；槽位列表正确显示当前快照大小与 revision，并正确判断是否还有下一页。
- 通知列表：正确读取新响应结构中的通知条目（旧结构仍兼容）。
- 好友在线：正确读取聚合结构中的好友列表与在线状态（旧结构仍兼容）。
- 地图详情：正确读取详情预览图与地图模式（模式现为数组，以「Survive, Attack」形式合并显示）。
- 在线活动：发布「正在游玩」状态时补上服务端必填的 `game.id`。

### 校验

- 通过 Xenon / XenonCore 编译、Checkstyle 与全部单元测试；新增云存档与好友在线的 fixture 测试，并更新通知、地图详情与 API URL 解析测试。

## English

Xenon v1.14.1 is a bug-fix release: it fixes community mod installation file names and duplicate installs, unrecognized release bundles, and MDTBBS cloud saves, notifications, friend presence, map details and Rich Activity parsing against the current `/api/v1` contract.

### Mod management

- Mods installed from the community index and GitHub direct install now keep the release asset name (e.g. `LogicSugar-v5.7.0.jar`) instead of the temporary download name.
- Installing a newer version of the same mod replaces the older archive (matched by internal mod name) instead of leaving two archives of which the game silently loads only one; when the target name belongs to a different mod, a numbered sibling name is used instead of overwriting it.
- Archives that look like mods by extension but contain no `mod.hjson`/`mod.json` (release bundles such as `Mod.zip` wrapping `Mod.jar`, source archives) are listed as "unrecognized" with a reason; installing them fails with a clear error instead of dropping an unusable file into `mods/`.
- The installed list reports "N mods installed, M file(s) unrecognized" when such files exist.

### MDTBBS community features (current `/api/v1` contract)

- Cloud saves: upload and download URLs are no longer doubled into `/api/v1/api/v1/...`; slots show the current snapshot size and revision and correctly report whether another page exists.
- Notifications: entries are read from the new response shape (legacy responses still work).
- Friend presence: the friend list and online status are read from the aggregate shape (legacy responses still work).
- Map details: the detail preview image and map modes are read correctly (modes are now an array, shown as "Survive, Attack").
- Rich Activity: publishing "playing" now includes the server-required `game.id`.

### Verification

- Passed Xenon / XenonCore compilation, Checkstyle and all unit tests; added fixture tests for cloud saves and friend presence and updated the notification, map detail and API URL resolution tests.
