## 中文

Xenon v1.9.0 是面向 Mindustry 的正式版本，重点改进了日志查看体验和国内网络环境下的版本、Mod 下载稳定性。

### 主要更新

- 崩溃退出提示新增“打开日志文件”，可直接打开本次实例的 `last_log.txt`。
- 将“崩溃报告”入口调整为“日志”，并始终提供“最后的日志”快捷入口。
- 改进 Mindustry 实例退出事件处理，确保能够定位到正确实例的数据目录和日志文件。
- 更新 Xenon 品牌与下载镜像配置，优化启动器首页体验。

### 下载与网络

- `play.mindustry.men` 请求会在每次访问前解析 IPv4 地址，并通过 IP 直连，降低域名拦截对下载的影响。
- 改进 GitHub Release API、Mod 索引、热门 Mod 资产缓存和镜像探测链路。
- 保留镜像失败后的重试与回退机制，提升版本和 Mod 下载成功率。

### 校验

- 通过 XenonCore 全量测试、Checkstyle 和 Xenon 编译验证。

## English

Xenon v1.9.0 is the stable Mindustry-focused release, with a better log workflow and more reliable version and mod downloads in restricted network environments.

### Highlights

- Crash-exit dialogs now include an **Open log file** action for the instance's `last_log.txt`.
- Renamed the former **Crash reports** entry to **Logs**, with a persistent **Last log** shortcut.
- Improved process-exit event handling so Xenon opens the correct instance data directory and log.
- Refreshed Xenon branding and download-mirror configuration, together with a polished launcher home page.

### Downloads and networking

- Requests to `play.mindustry.men` resolve its IPv4 address before each request and connect directly by IP, reducing the impact of domain-level blocking.
- Improved GitHub Release API, mod-index, popular-mod cache, and mirror-probing paths.
- Retained retry and fallback behavior when a mirror is unavailable, improving version and mod download reliability.

### Verification

- Passed the full XenonCore test suite, Checkstyle, and Xenon compilation.
