> Windows ships a single-file `.exe`; macOS / Linux need **Java 17+** for the `.jar`

## 中文

### 修复

- **账户卡片点击选中**：在「账户」页点卡片主体（头像、昵称或空白处）即切换 Mindustry UID，单选圆点、侧边栏的当前账户和 `config.json` 里的 `selectedAccount` 同步更新。上一版点卡片没有反应。
- **删除账户后的选中**：删除当前选中的账户后，自动改选列表里的第一个账户；只有把账户全部删空才会变成「无选中」（此时侧边栏显示未选择账户）。之前删掉选中项后没有任何账户被选中。
- **移动账户保持选中**：在「便携」与「全局」之间移动当前选中的账户后，选中状态仍停留在该账户上；卡片右侧的「移动 / 复制 UUID / 删除」按钮也不再改变选中。
- **应用内更新真正覆盖旧版**：jar 安装的更新过去会直接从临时目录启动新版本、却不替换已安装的 jar，于是下次启动又退回旧版；现在改为以 `--apply-to` 交接，由新进程把自己覆盖到已安装的 jar 上再启动它，文件被旧进程占用时会等待重试。单文件 exe 与打包安装保留原来的 jar 文件名，避免启动器找不到 jar；写入被拒绝时给出手动下载提示，而不是静默回到旧版本。

### 说明

- 配置格式、账户标识（`username:uuid`，可选 `$GLOBAL:` 前缀）与实例目录结构均未改动，升级不需要任何迁移。
- 手动下载覆盖安装依旧是可行的备用更新方式。

## English

### Fixed

- **Clicking an account card selects it**: on the Accounts page, clicking a card body (avatar, nickname, or empty area) now switches the Mindustry UID, and the radio dot, the sidebar account entry, and `selectedAccount` in `config.json` follow. The previous build ignored those clicks.
- **Selection after deleting an account**: deleting the selected account selects the first remaining one; only an empty list leaves the launcher with no account selected (the sidebar then shows the missing-account entry). Previously deleting the selected account left nothing selected.
- **Moving an account keeps it selected**: moving the selected account between Portable and Global keeps the selection on it, and the Move / Copy UUID / Delete buttons on the card no longer change the selection.
- **The in-app update really replaces the old build**: a jar update used to start the downloaded launcher from the temp directory without replacing the installed jar, so the next launch silently ran the old version again. The download is now handed over with `--apply-to`, the new process copies itself over the installed jar (`installJar`) and starts that installed copy, and the copy waits for the exiting process to release the file. Single-file and packaged installs keep their jar file name so the launcher can still find it, and a refused write reports the manual-download hint instead of falling back to the old version.

### Notes

- The config format, account identifiers (`username:uuid` with an optional `$GLOBAL:` prefix) and instance layout are unchanged; no migration is required.
- Downloading the installer manually still works as a fallback update path.
