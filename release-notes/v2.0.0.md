## 中文

### 本次新增

- **MDTBBS 联机升级到 1.7.0**：可见范围与加入权限拆成两个正交选项，支持「需要房主批准」、公开房间大厅、实时 WebSocket 事件与好友加入动作；房主先建房、8 秒内启动游戏也能连上
- **伪局域网自动发现**：客人连上中继后，房间会直接出现在 Mindustry 的局域网列表，不再必须粘贴 `127.0.0.1:6567`；20151 被占用时静默降级，复制地址仍可用
- **云存档完整契约**：冲突可选择保留两份 / 覆盖云端（先备份云端副本）/ 用云端覆盖本地；支持 `no_upload_required`、上传元数据（游戏版本、地图、波次、Mod、设备 ID）、ETag 校验、槽位重命名与快照删除
- **整实例云归档**：把存档、地图、蓝图、`settings.bin` 与 Mod 清单打成一个包；官方索引 Mod 不打包字节，恢复后自动补齐；按实例开启启动前拉取 / 退出后上传，冲突永不自动裁决
- **Mod 开发工作流**：实例页「开发」页可配置工程目录、构建命令与产物 glob，源码变化自动重建、部署并重启游戏
- **无窗口 CLI 与启动脚本**：`--list/--launch/--export/--get/--set`，`.bat`/`.sh` 导出，以及 `xenon://launch` / `xenon://open` 深链
- **回收站、自动备份与分组**：删除的实例与存档归档可恢复；长会话退出后自动备份存档；Mindustry 实例支持单层分组与 `group:` 筛选

### 本次修复

- 「使用加入码」不再发送已废弃的 `unlisted/open`，不会再 400；旧值会在请求前归一化
- 首次心跳立即发送，避免中继分配时命中 `PEER_UNAVAILABLE`
- 房主桥接对本地游戏端口重试 8 秒，先建房后开游戏也能连

### 说明

- 自动同步、伪局域网、Mod 开发、自动备份均可在实例/设置中关闭；冲突始终需要用户选择

## English

### Added

- **MDTBBS multiplayer upgraded to 1.7.0**: visibility and join policy are orthogonal, with host approval, a public lobby, realtime WebSocket events and friend join actions; creating the room before starting the game now works
- **Pseudo-LAN discovery**: once the guest relay is up, the room appears directly in Mindustry's LAN list instead of requiring a pasted `127.0.0.1:6567`; a busy `20151` degrades silently and the copyable address remains
- **The full cloud-save contract**: keep both copies / overwrite the cloud (after backing up its head) / overwrite local from the cloud, plus `no_upload_required`, upload metadata (game, map, wave, Mods, device id), ETag validation, slot renaming and snapshot deletion
- **Whole-instance cloud archives**: saves, maps, schematics, `settings.bin` and a Mod manifest in one archive; indexed Mods are re-downloaded instead of packed, and per-instance pre-launch pull / post-exit push never resolves a conflict automatically
- **Mod development workflow**: a Development tab configures the project directory, build command and artifact glob, then rebuilds, deploys and restarts on source changes
- **Headless CLI and launch scripts**: `--list/--launch/--export/--get/--set`, `.bat`/`.sh` export, and `xenon://launch` / `xenon://open` deep links
- **Recycle bin, automatic backups and groups**: deleted instances and save archives can be restored; long sessions back up saves after exit; Mindustry instances support a single group and a `group:` filter

### Fixed

- The join-code preset no longer sends the removed `unlisted`/`open` values and can never 400 again; deprecated values are normalised before the request
- The first peer heartbeat is sent immediately, removing a relay `PEER_UNAVAILABLE` race
- The owner bridge retries the local game port for eight seconds, so starting the game after creating the room works

### Notes

- Automatic sync, pseudo-LAN, Mod development and automatic backups can all be disabled; conflicts always require an explicit choice
- The README competitor table was re-verified as of 2026-10-23
