## 中文

Xenon v1.14.0 是一次功能更新：在原有的安装、实例与社区能力之上，补齐了 MDTBBS 官方联机，吸收了多个竞品启动器的实用功能，并把用户手册重写为当前版本。

### MDTBBS 联机

- 「联机」页新增 MDTBBS 联机区块：创建房间时可选择「好友可直接加入 / 仅邀请 / 使用加入码」，「复制加入码」一键分享给好友。
- 房主照常主持游戏；客人加入并等待中继连接后，把 `127.0.0.1:<端口>` 粘贴到游戏「加入服务器」一次即可，无需公网 IP 或额外工具。
- 支持好友邀请：可从好友列表直接邀请；对方从网页或好友面板收到的邀请会通过 `xenon://join?intent=` 唤起启动器并自动加入。
- 数据经 MDTBBS 官方中继转发，凭证自动续期；会话生命周期经过串行化处理，取消创建不会遗留会话。

### 联机与下载

- 「联机」页内置官方公共服务器列表（自动走镜像并在离线时使用缓存），支持复制地址与一键启动游戏。
- EasyTier P2P 房间：六位房号即可组网，按需下载 EasyTier；修复了新版 EasyTier 压缩包目录嵌套导致"找不到 easytier-core"的问题。
- 下载支持**断点续传、暂停/继续与取消清理**：中断后重新下载从已下载字节继续，暂停不占带宽，取消会删除临时文件。
- 设置 → 下载新增 **GitHub 账号**：填入令牌后 API 限额从每小时 60 次提升到 5000 次，令牌只用于直连 `api.github.com`，不会发给镜像站。

### 实例工具

- **版本时代标注**：版本列表按 V4/V5/V6/V7/V8 与 Java 8/17 需求标注，旧版本给出兼容性提示；断网时显示内置离线版本快照。
- **更新说明**：版本列表可查看 release notes，支持表格与图片渲染。
- **迁移数据**：可在实例之间复制存档、mod、蓝图、地图、`settings.bin` 与游玩统计；安装向导第 3 步也支持从现有实例复制数据。
- **自动内存**：按已启用 mod 的体积推荐堆大小（显式 `-Xmx` 与手动设置优先），并在健康检查页展示。
- **游玩时长与健康检查**：记录每个实例的游玩时间，体检报告会列出实例信息与兼容性问题。
- **回收站删除**：删除存档、mod、蓝图、地图乃至整个实例时优先移入系统回收站，误删可找回。
- **便携数据模式**：在启动器目录放置 `Xenon.portable` 标记（设置页可一键开启）后，所有数据保存在同目录的 `XenonData/`，重启生效。

## English

Xenon v1.14.0 is a feature release: on top of the existing installation, instance and community features it adds native MDTBBS multiplayer, absorbs the practical ideas from several competing launchers, and rewrites the user guide for the current version.

### MDTBBS multiplayer

- The Netplay page gains an MDTBBS section: create a room with "friends can join directly / invite only / join code", and share the join code with one click.
- The host keeps hosting in Mindustry as usual; guests join, wait for the relay, and paste `127.0.0.1:<port>` into the in-game join dialog once. No public IP or extra tooling required.
- Friend invites work both ways: invite directly from the friend list, and invites received on the website or in the friends panel open the launcher through `xenon://join?intent=` and join automatically.
- Traffic goes through the official MDTBBS relay and credentials renew automatically; the session lifecycle is serialised so cancelled attempts cannot leave orphaned sessions.

### Multiplayer and downloads

- The Netplay page ships the official public server directory (mirror-backed, cache when offline) with copy-address and one-click launch.
- EasyTier P2P rooms with six-digit codes and on-demand EasyTier download; fixed the "archive did not contain easytier-core" failure caused by nested folders in newer EasyTier archives.
- Downloads are **resumable**: interrupted transfers continue from the last byte, pause/resume is available in the progress dialog, and cancelling removes the partial data.
- Settings → Download gains a **GitHub account** field: a token raises the API limit from 60 to 5000 requests per hour and is only ever sent to `api.github.com`, never to mirrors.

### Instance tools

- **Version eras**: version lists tag V4/V5/V6/V7/V8 and Java 8/17 requirements, warn about legacy builds, and fall back to a bundled offline snapshot when the network is unavailable.
- **Release notes**: viewable from the version list with table and image rendering.
- **Migrate data**: copy saves, mods, schematics, maps, `settings.bin` and playtime between instances; the install wizard can seed a new instance from an existing one.
- **Automatic heap**: suggested from the enabled mod set (explicit `-Xmx` and manual settings win) and shown on the health page.
- **Playtime and health check**: per-instance playtime plus a report with instance details and compatibility findings.
- **Trash-first deletion**: saves, mods, schematics, maps and whole instances go to the system trash first.
- **Portable data mode**: place a `Xenon.portable` marker next to the launcher (toggle in the settings) and all data lives in `XenonData/` after a restart.

### Documentation

- Rewrote the user guide (docs/USAGE.md) for the current workflows and updated the README sections about netplay and instance tools.

### Verification

- Passed Xenon / XenonCore compilation, Checkstyle, translation checks and all unit tests.
- Added regression tests for resumable/paused/cancelled downloads, MDTBBS relay framing plus a real tunnel end-to-end against an in-test RFC 6455 relay agent, session lifecycle and cancellation cleanup, cross-instance migration, heap policy, version eras, release-note Markdown rendering, and EasyTier asset/nested-folder resolution.
