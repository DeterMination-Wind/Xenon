## 中文

### 本次修复

- **「预装 Mod」列表恢复加载**：安装向导的社区 Mod 索引改为读取项目镜像的缓存副本（按 IP 直连），`raw.githubusercontent.com` 连不上时也能列出全部 900+ 个 Mod
- **镜像测速不再被第一个失败拖垮**：以前只要有一个镜像的 DNS 立刻失败，就会放弃全部镜像并回退到 GitHub 直连；现在会等待第一个真正响应的镜像
- **高星 Mod 下载地址修正**：镜像的 Release 资源走 `镜像/https://github.com/...` 的正确路径，不再命中镜像的 403 规则
- **国内缓存镜像恢复**：`play.mindustry.men` 重新指向承载缓存的服务器，下载与索引都会优先走该镜像

### 说明

- 镜像不可达时会自动回退到其他 GitHub 镜像或直连，不需要手动切换
- 本次为修复版本，实例、存档与联机数据格式均未改动

## English

### Fixed

- **The "preload mods" list loads again**: the install wizard now reads the community mod index from the project mirror's cached copy (connected by IP), so all 900+ mods are listed even when `raw.githubusercontent.com` is unreachable
- **Mirror probing no longer gives up on the first failure**: a single instant DNS failure used to abort the race and fall back to a direct GitHub connection; the launcher now waits for the first mirror that actually answers
- **Correct mirror URL for high-star mod downloads**: release assets now use the mirror's `https://github.com/...` route instead of hitting its 403 rule
- **The domestic cache mirror is back**: `play.mindustry.men` points at the cache server again, so the index and downloads prefer it

### Notes

- When a mirror is unreachable the launcher falls back to the other GitHub mirrors or a direct connection automatically
- This is a fix-only release; instance, save and multiplayer data formats are unchanged
