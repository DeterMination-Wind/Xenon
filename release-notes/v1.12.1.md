## 中文

Xenon v1.12.1 让国内下载优先走像素工厂文件站。

### 主要更新

- 下载 GitHub 上的 Mindustry 发布文件时，若文件站清单里有同一份，先从 `https://file.mdtbbs.cn` 获取；文件站失败或清单没有该文件时，再竞速其他镜像。
- 下载客户端改为 HTTP/1.1。握手被对端掐断时会重试一次，并把旧的 `d.file.mdtbbs.cn` 改写到 `file.mdtbbs.cn`；仍然失败则回退到对应的 GitHub 发布地址。
- 国内原版版本列表改为读取 `https://file.mdtbbs.cn/api/v1/mindustry/manifest.json`，不再解析文件站网页。

### 校验

- 通过 `MdtbbsVersionListTest` 与 `MdtbbsFileMirrorTest`。

## English

Xenon v1.12.1 prefers the MDT File station for Mindustry downloads.

### Highlights

- When a GitHub Mindustry release asset is listed in the file-station manifest, it is downloaded from `https://file.mdtbbs.cn` first. If the station fails or does not list the file, the existing mirror race runs.
- Download clients use HTTP/1.1. A terminated handshake is retried once, rewriting a legacy `d.file.mdtbbs.cn` host to `file.mdtbbs.cn`, then falls back to the GitHub release asset.
- The mainland vanilla version list reads `https://file.mdtbbs.cn/api/v1/mindustry/manifest.json` instead of scraping the file-station HTML.

### Verification

- Passed `MdtbbsVersionListTest` and `MdtbbsFileMirrorTest`.
