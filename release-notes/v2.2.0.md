## 中文

### 新增

- **Mod 浏览器默认「推荐」榜**：Xenon 现在从下载量、星标、发布频率、近期提交、最近发布时间和最新版兼容性计算推荐分，默认按「持续维护优先」排序。每行显示 `#N` 名次，工具栏的「评选标准」可以查看当前权重和数据来源；「社区热度」与「全部」仍可一键切换。
- **推荐数据独立更新**：榜单由 `scripts/mod-ranking/generate.mjs` 从 `MDTCopper/mindustry-data-index` 生成，GitHub Actions 每天刷新 `remote/mod-ranking.json`，项目镜像每小时缓存一次。客户端优先走国内镜像，失败后回退到 GitHub 镜像和 `raw.githubusercontent.com`，离线时使用上一次成功缓存。
- **Mod 安装状态**：从所选实例的 `mods/` 目录读取本地版本，每行显示「安装 / 更新 / 已安装」；更新行显示本地 → 最新版本，已安装行禁用安装按钮。
- **可脚本化的无头 CLI**：新增 `--version`、`--list-backups`、`--check-updates`、`--import`、`--restore-backup`、`--delete-backup`、`--delete-version`，补充退出码约定和 `--yes` 破坏性操作确认；实例引用忽略大小写、重复/全角空格和可选的 `v` 前缀。`--restore-backup` 会先备份当前槽位，启动器运行时拒绝修改并返回退出码 6。

### 调整

- CLI 命令改为在独立进程中运行，不再转发给已运行的启动器，因此脚本能拿到真实退出码。
- `--set` 在启动器运行时拒绝写入（退出码 6），避免和启动器自身的配置写入互相覆盖。
- `README.md` 现在是中文首页，`README_EN.md` 是英文版，二者顶部互相链接；竞品矩阵移入两版 README，最后更新时间由 workflow 根据最新 tag 自动维护。
- README 增加了实例列表、下载页、实例详情和联机页的真实截图。
- 发布构建改为从当前工作树在本地生成，并在推送 tag 前把 jar / exe / 便携包和 SHA-256 一起暂存到 `构建/Xenon`。

### 说明

- 「推荐」是**维护优先**榜单，不是累计下载量榜；喜欢按社区热度浏览时请切到「社区热度」。
- 当前权重为：社区认可（下载 + 星标）35%、维护活跃（发布频率 + 近 13 周提交）35%、近期更新 20%、最新版兼容 10%。只有达到最低社区信号且 365 天内有发布的条目进入推荐名次；其余条目仍会出现在「社区热度」和「全部」。
- 推荐数据依赖第三方索引 `MDTCopper/mindustry-data-index`；数据不可用时启动器回退到按星标排序，并显示提示。
- 实例目录、存档格式、云存档和 `.xenon` 包格式均未改动。

## English

### Added

- **Recommended tab in the Mod browser**: Xenon now scores indexed mods from downloads, stars, release cadence, recent commits, release recency, and latest-version compatibility, and opens on a maintenance-first order. Each row shows a `#N` badge, and the **Methodology** link in the toolbar explains the current weights and data source. **Community heat** and **All mods** stay one click away.
- **Independently refreshed ranking data**: `scripts/mod-ranking/generate.mjs` builds the ranking from `MDTCopper/mindustry-data-index`; GitHub Actions refreshes `remote/mod-ranking.json` daily and the project mirror caches it hourly. The client tries the domestic mirror first, then the GitHub mirror, then `raw.githubusercontent.com`, and falls back to the last successful cache when offline.
- **Mod install state**: rows read the selected instance's `mods/` folder and show Install, Update, or Installed; update rows show local → latest, and installed rows disable the install action.
- **Scriptable headless CLI**: new `--version`, `--list-backups`, `--check-updates`, `--import`, `--restore-backup`, `--delete-backup`, and `--delete-version` commands, a documented exit-code contract, `--yes` for destructive actions, and instance references that ignore case, repeated/full-width spaces, and an optional `v` prefix. `--restore-backup` backs up the live slot first, and mutations are refused with exit code 6 while a launcher is running.

### Changed

- CLI commands now run in their own process instead of being forwarded to a running launcher as deep-link arguments, so scripts get the command's real exit code.
- `--set` refuses to write while a Xenon launcher is running (exit code 6) instead of racing the launcher's own config write.
- `README.md` is now the Chinese landing page and `README_EN.md` holds the English version; each links to the other at the top. The competitor matrix moved into both READMEs, and its last-updated line is rewritten from the latest tag by a workflow.
- The README now shows real screenshots of the instance list, download page, instance detail, and multiplayer page.
- Release builds are produced locally from the working tree and staged with jar / exe / portable zip and SHA-256 files in `构建/Xenon` before the tag is pushed.

### Notes

- **Recommended** is a maintenance-first list, not a lifetime-download list; switch to **Community heat** for popularity.
- Current weights: community signal (downloads + stars) 35%, maintenance (release cadence + 13-week commits) 35%, release recency 20%, latest-version compatibility 10%. Only entries with a minimum community signal and a release within 365 days receive a recommendation rank; the rest remain available under Community heat and All mods.
- Ranking data depends on the third-party `MDTCopper/mindustry-data-index` dataset. When it is unavailable, the launcher falls back to the stars order and shows a notice.
- Instance layout, save formats, cloud saves, and the `.xenon` package format are unchanged.
